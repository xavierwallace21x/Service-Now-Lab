# Service-Now-Lab
## Overview

This project demonstrates hands-on practice with ServiceNow in a simulated IT help desk environment. I worked with incidents, prioritized and routed tickets, documented troubleshooting steps, resolved a user account issue, and created a knowledge base article.

## Skills Practiced

- Incident Management
- Ticket Prioritization
- Ticket Assignment & Escalation
- Help Desk Troubleshooting
- Technical Documentation
- Knowledge Base Management
- User Account Support
- Active Directory Troubleshooting
- ServiceNow Navigation

## Tools Used

- ServiceNow
- Active Directory Users and Computers (ADUC)
- Windows
- ## What I Learned

This lab helped me practice the workflow of an IT support technician using a ticketing system. I gained experience reviewing and prioritizing incidents, documenting troubleshooting steps, routing issues to the appropriate support team, resolving common user issues, and creating knowledge base documentation.

## Key Takeaways

- Proper ticket documentation is important for communication between support teams.
- Impact and urgency help determine ticket priority.
- Tickets should be routed to the correct support group when escalation is required.
- Resolution notes should clearly explain the troubleshooting performed and final outcome.
- Knowledge articles can help technicians resolve recurring issues more efficiently.
